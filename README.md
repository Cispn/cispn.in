# CisPn — Personal Bio Site

A personal bio page built and designed by **[CisPn](https://github.com/cispn)**.

## Features

- Live Discord presence via [Lanyard](https://github.com/Phineas/lanyard)
- Real-time Spotify activity with synced lyrics from [lrclib](https://lrclib.net)
- Dynamic video backgrounds with volume control
- Animated typewriter intro
- Smooth motion via [Framer Motion](https://www.framer.com/motion/)

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
